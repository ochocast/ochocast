`speech-fr.wav` is a synthetic French voice fixture generated locally with the
macOS Thomas voice, then normalized to 16 kHz mono PCM with FFmpeg. It contains
no personal data or external recording.

Text: « Bonjour, cette vidéo présente le projet OchoCast. Les sous-titres
automatiques permettent de comprendre les vidéos. Merci et bonne journée. »
