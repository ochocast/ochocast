`speech-fr.wav` is a synthetic French speech fixture generated with eSpeak NG
and converted to 16 kHz mono PCM with FFmpeg. eSpeak NG is available under
GPL-3.0-or-later; the generated recording contains no macOS System Voices.

Text: « Bonjour, cette vidéo présente le projet OchoCast. Les sous-titres
automatiques permettent de comprendre les vidéos. Merci et bonne journée. »

`video-short.mp4` is an original blue test video generated with FFmpeg's
`color` source; it contains no third-party media. The default browser tests
use this fixture without installing FFmpeg on the self-hosted runner.
